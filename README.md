## 📂 Projects

<img src="https://readme-typing-svg.demolab.com?font=Orbitron&size=26&duration=1&pause=100000&color=58A6FF&center=false&vCenter=true&width=400&height=45&lines=AEROREASON" alt="AeroReason"/>

**Hybrid AI system for aircraft engine predictive maintenance**

A neuro-symbolic pipeline built to close the gap between prediction and explanation in safety-critical maintenance. An LSTM model estimates Remaining Useful Life (RUL) from multi-sensor turbofan data, and a LLaMA3-driven chain-of-thought layer turns that number into a reasoned maintenance recommendation, with rule-based post-processing keeping the output actionable. Trained and validated on the NASA C-MAPSS benchmark; shipped with a FastAPI + React fleet-monitoring dashboard.

**AI-integrated smart healthcare ecosystem**

A full-stack, offline-first patient record system built around NFC (MIFARE DESFire EV1) for encrypted, tap-to-access medical data with no network dependency. Paired with an XGBoost classifier for disease risk scoring, TrOCR for parsing handwritten prescriptions, and a Mistral-based chatbot for patient-facing health queries.
