### § FIELD NOTES — SELECTED WORK

<br/>

**AeroReason** — *predictive maintenance, aircraft turbofan engines*
An LSTM estimates Remaining Useful Life; a LLaMA3 reasoning layer turns
that number into an explanation a maintenance engineer can act on.
Trained on the NASA C-MAPSS benchmark. Published — *ISJEM*, Impact Factor 8.072.

![Python](https://img.shields.io/badge/-Python-2F4F4F?style=flat-square) ![PyTorch](https://img.shields.io/badge/-PyTorch-D2691E?style=flat-square) ![LLaMA3](https://img.shields.io/badge/-LLaMA3-E8B94E?style=flat-square&labelColor=E8B94E&color=E8B94E)

<br/>

**MediVault** — *offline-first healthcare records*
Encrypted patient data over NFC (MIFARE DESFire EV1), an XGBoost risk
classifier, and TrOCR reading prescriptions no one can read by hand.

![Flutter](https://img.shields.io/badge/-Flutter-2F4F4F?style=flat-square) ![FastAPI](https://img.shields.io/badge/-FastAPI-D2691E?style=flat-square) ![XGBoost](https://img.shields.io/badge/-XGBoost-E8B94E?style=flat-square)

<br/>

**TasteTone** — *sentiment analysis, browser extension*
Samples five Zomato reviews, scores their tone, surfaces the best
and worst of them before you've finished scrolling.
