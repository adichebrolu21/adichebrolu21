### ✈️ AeroReason
**Hybrid AI for aircraft engine predictive maintenance** &nbsp; ![Published](https://img.shields.io/badge/PUBLISHED-238636?style=flat-square) ![IF](https://img.shields.io/badge/IMPACT%20FACTOR-8.072-1f6feb?style=flat-square) ![Journal](https://img.shields.io/badge/ISJEM-Vol.05%20Issue%2005-8b949e?style=flat-square)

A neuro-symbolic pipeline that closes the gap between prediction and explanation in safety-critical maintenance. An **LSTM** estimates Remaining Useful Life from multi-sensor turbofan data; a **LLaMA3** chain-of-thought layer turns that number into a reasoned maintenance recommendation, with rule-based post-processing keeping it actionable. Trained and validated on the **NASA C-MAPSS** benchmark, shipped with a **FastAPI + React** fleet-monitoring dashboard.
